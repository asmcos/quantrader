# 05 — 常用指标

这一课在均线和 MACD 之外，再算三条行情软件里最常见的指标：RSI、KDJ、布林带。价格仍用 01 的前复权日 K。公式按通达信的写法，方便和软件上的数字对照。

```bash
python3 rsi.py
python3 kdj.py
python3 boll.py
```

默认股票是 `sz002129`。周期可以跟在代码后面改。

| 文件 | 指标 | 默认参数 |
|------|------|----------|
| `rsi.py` | 相对强弱 | 6、12、24 |
| `kdj.py` | 随机指标 | 9, 3, 3 |
| `boll.py` | 布林带 | 20 日，2 倍标准差 |

`bars.py` 负责取开高低收，以及通达信的 `SMA(X, N, M)`。RSI 和 KDJ 都用到它，它不是简单移动平均。

---

## 通达信 SMA(X, N, M)

03 里的 SMA 是「最近 N 天加总除以 N」。这里同名的函数是另一件事：

```text
Y = (M × 今天的 X + (N - M) × 昨天的 Y) / N
```

M=1 时，今天只占 1/N，其余是昨天的结果。数字会跟着行情走，但转弯比收盘价慢。RSI、KDJ 的默认参数都取 M=1。

---

## RSI

RSI 看的是：最近这些涨跌里，上涨占了多少。

先算和昨天比的变动。上涨只保留涨的部分，跌的那天记 0。另一边用变动的绝对值，涨和跌都算进总波动。

```text
涨幅 = max(收盘 - 昨天收盘, 0)
振幅 = |收盘 - 昨天收盘|
RSI  = SMA(涨幅, N, 1) / SMA(振幅, N, 1) × 100
```

结果在 0 到 100 之间。

- 接近 100：这段时间几乎天天涨，跌的天数或跌幅很少。
- 接近 0：这段时间几乎天天跌。
- 50 附近：涨的幅度和跌的幅度差不多。

通达信同时画三条，周期是经验值，不是定理：

| 参数 | 大约覆盖 | 特点 |
|------|----------|------|
| 6 | 约一周多 | 抖得厉害，经常碰到 80 和 20 |
| 12 | 约两周半 | 比 6 稳一些 |
| 24 | 约一个月 | 更慢，大段行情才离开 50 |

西方教材常用 **14**，算法相同，只把 N 换成 14。`python3 rsi.py sz002129 14` 就是这一条。

软件上常把 80 以上叫超买、20 以下叫超卖。那是说涨跌已经挤在一侧，并不是价格一定会回头。强势行情里 RSI 可以在 80 上方停很多天。

第一根没有「昨天」，RSI 从第二根才有意义。周期越长，开头越受起点影响。

## KDJ

KDJ 看收盘价落在最近 N 天价格区间的什么位置。

```text
RSV = (收盘 - N日最低) / (N日最高 - N日最低) × 100
K   = SMA(RSV, M1, 1)
D   = SMA(K, M2, 1)
J   = 3×K - 2×D
```

RSV 是当天的位置：收在区间最上沿是 100，最下沿是 0。最高价等于最低价时，这一天没有区间，脚本不算 RSV。

K 是 RSV 的平滑，D 是 K 的再平滑，所以 D 比 K 更钝。J 把 K 相对 D 的距离放大：K 在 D 上面时 J 更高，K 在 D 下面时 J 更低。J 可以大于 100 或小于 0，这是公式的结果，不是算错。

| 参数 | 默认 | 作用 |
|------|------|------|
| N | 9 | 用多少根 K 线定最高、最低 |
| M1 | 3 | RSV 平滑成 K |
| M2 | 3 | K 平滑成 D |

读法：

- K、D 在 80 以上：收盘经常靠近这段时间的高点。
- K、D 在 20 以下：收盘经常靠近低点。
- K 上穿 D：短位置从弱于自己的平滑，变成强于它。下穿相反。
- J 到 100 以上或 0 以下：K 和 D 拉开了，位置极端。极端可以维持，不一定当天转向。

N 要满 9 根才有高低区间。K、D 还要再平滑几天，开头一段同样不稳定。

## 布林带

中轨是收盘价的 20 日简单均线。上下轨是这条均线加减 2 倍标准差。标准差用这 20 天的价格离散程度，除以 20（通达信 STD）。pandas 默认的标准差除以 19，数字会略大，本课不用那个。

```text
中轨 = MA(收盘, 20)
上轨 = 中轨 + 2 × STD(收盘, 20)
下轨 = 中轨 - 2 × STD(收盘, 20)
```

| 参数 | 默认 | 作用 |
|------|------|------|
| 周期 | 20 | 中轨和标准差的窗口，大约一个月 |
| 倍数 | 2 | 带子多宽。改成 1 更窄，改成 3 更宽 |

带宽 `width = (上轨 - 下轨) / 中轨 × 100`，是上下轨距离占中轨的百分比。价格波动大，带子变宽；连着小阴小阳，带子变窄。

收盘在上轨附近，是相对这 20 天均值偏高；在下轨附近，是偏低。碰到轨道不等于会折返。沿上轨往上走，在上涨行情里很常见。

不满 20 根没有中轨和上下轨。
